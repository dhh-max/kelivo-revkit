 APK 逆向破解助手 · 工具包安装说明
================================================

本文件夹包含 APK 逆向破解工作流所需的全部工具包。
按以下步骤在 Operit 内导入即可。

------------------------------------------------
一、文件夹内容
------------------------------------------------
1. 56al在线脱壳.js   —— 云脱壳工具包（56.al / nop.gs）
2. logfox日志工具.js —— 日志/崩溃分析工具包（冒烟验证、崩溃诊断、ANR）
3. 加固特征库.js      —— 加固壳特征识别数据库（内置49种壳）
4. 安装说明.txt       —— 本文件
5. <你的>角色卡.png  —— 角色卡（含完整逆向提示词，放入本文件夹）


------------------------------------------------
二、安装步骤
------------------------------------------------
【第1步】导入工具包
  把本文件夹里的 3 个 .js 文件复制到 Operit 的包目录：

      /storage/emulated/0/Android/data/com.ai.assistance.operit/files/packages/

  然后重启 Operit（或重新加载包列表），三个工具包即可被识别。

  ※ 校验：在 Operit 的包管理里应能看到 3 个已启用的包——
     - 56al_tuoke       （脱壳修复工具包）
     - logfox_toolkit   （日志/崩溃分析工具包）
     - 加固特征库        （加固特征库）

【第2步】导入角色卡
  在 Operit 角色卡管理中，导入本文件夹的 PNG 角色卡图片。
  角色卡内含完整的「APK 逆向破解助手」提示词，导入后设为活跃即可。


------------------------------------------------
三、56al 云脱壳 · 首次登录（必须）
------------------------------------------------
⚠️ 注意：脱壳包已移除内嵌账号，每位用户需自行登录自己的 56.al 账号。
首次使用「56al在线脱壳」包前，先完成登录：

  1. 调用  tuoke_login_url   获取 56.al 第三方授权链接
     （支持 github / qq / gitee / microsoft / wx）
  2. 浏览器打开链接完成授权登录
  3. 调用  tuoke_set_cookie   把浏览器里的 Cookie 粘贴进来
     （Cookie 会自动持久化保存，之后无需重复登录）

  ※ 也可用 tuoke_browser_login 自动读取 Operit 内置浏览器里的登录 Cookie。
  ※ 若未登录直接调用 tuoke_all，会提示「未检测到登录 Cookie，请先登录」。


------------------------------------------------
四、三个工具包的用途速查
------------------------------------------------
■ 56al_tuoke（56al在线脱壳）
   云脱壳：上传 APK → 云端自动脱壳 → 下载 → 解压 → 修复 dex 头。
   一键入口：tuoke_all(apk_path=APK路径)
   小包(≤8MB)走 tuoke_upload，大包(>8MB)自动走分片 tuoke_upload_big。

■ logfox_toolkit（logfox日志工具）
   冒烟验证与崩溃诊断闭环：
   - apk_launch_test     安装+启动冒烟，检查是否存活/崩溃/前台Activity
   - log_read_crash      读取并解析 Java/Native/libc 崩溃
   - log_analyze_anr     读取 ANR（无响应）事件
   - log_capture_start/stop  后台录制日志
   - log_parse_java_crash / log_parse_native_crash  解析已有日志

■ 加固特征库
   壳识别与删壳要点查询：
   - identify_by_stub      按桩类 Application 查壳
   - identify_by_feature   按特征文件查壳
   - identify_combined     综合判定（桩类+lib+assets）


------------------------------------------------
五、常见问题
------------------------------------------------
Q: 导入后工具包没出现？
A: 确认 .js 文件已放到 packages/ 目录且重启了 Operit。
   文件名可保留中文，包实际以文件头 METADATA 的 name 识别。

Q: 用脱壳包时报「未检测到登录 Cookie」？
A: 按第三节完成 56.al 登录即可。

Q: 三个包和角色卡的关系？
A: 角色卡(提示词)指挥 AI 调用这三个工具包；三者缺一不可。
   提示词里已配置好各包的调用规则，导入后即可协同工作。
